# Rivaa Bridal Studio — Premium Demo Website

A luxury bridal editorial website for Rivaa Bridal Studio, a bridal beauty and makeup artistry studio in Mount Lavinia, Sri Lanka.

## Project Structure

```
rivaa-bridal-studio/
├── index.html          # Homepage
├── about.html          # About page
├── services.html       # Services page
├── gallery.html        # Gallery with filtering & lightbox
├── contact.html        # Contact page with form
├── css/
│   ├── style.css       # Main styles
│   ├── responsive.css  # Responsive styles
│   └── animations.css  # Animation styles
├── js/
│   ├── main.js         # Navigation, scroll, reveals
│   ├── gallery.js      # Gallery filtering & lightbox
│   └── contact.js      # Form validation & modal
├── assets/
│   ├── images/         # Image assets
│   └── icons/          # Icon assets
└── README.md
```

## How to Open

1. Open the `rivaa-bridal-studio` folder
2. Double-click `index.html` to open in your browser
3. Or right-click → Open with → your preferred browser

No server required — this is a static website.

## Features

- Responsive design (desktop, laptop, tablet, mobile)
- Mobile hamburger navigation with fullscreen overlay
- Scroll-triggered reveal animations
- Image lightbox with keyboard navigation
- Gallery filtering by category
- Contact form with client-side validation
- Success modal on form submission
- Smooth scrolling and page transitions
- Editorial typography with Google Fonts
- Luxury colour palette (ivory, beige, gold, charcoal)
